# Lessons Learned

## 1. Accuracy and Relevance Are Different

A response may directly answer a question while providing
incorrect information. Evaluators should assess each
criterion independently.

## 2. Instruction Following Must Be Explicitly Checked

Evaluation should include constraints such as word limits,
required formats, the number of requested examples, and
specific exclusions.

## 3. Evidence Matters More Than Confidence

Confident wording does not establish factual correctness.
Important claims should be checked against reliable sources.

## 4. Scoring Requires Consistency

Rubrics should define what different scores mean.
Comparable responses should be assessed using the same
criteria unless the task instructions require otherwise.

## 5. Numerical Averages Have Limitations

An average can conceal a critical failure. For example,
a response with excellent clarity but dangerous medical
misinformation should not automatically pass because its
average score is high.

## 6. Evaluation Requires Human Judgment

Automated scoring tools can assist with record-keeping,
but they cannot guarantee that a response is correct.
Human reviewers must consider evidence, context, and
the applicable evaluation guidelines.

## Future Improvements

- Add more examples across different domains.
- Record references used for factual verification.
- Test agreement between independent evaluators.
- Add automated input validation and report generation.
- Develop a method for flagging critical failures separately
  from ordinary scoring errors.
